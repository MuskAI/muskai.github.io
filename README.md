# Haoran Chen's Academic Homepage

This site is built from the official [al-folio](https://github.com/alshedivat/al-folio) academic template, version 0.16.3, and deployed with GitHub Pages.

The primary content files are:

- `_pages/about.md` for the homepage
- `_bibliography/papers.bib` for publications
- `_news/` for announcements
- `_data/cv.yml` for the CV page
- `_data/socials.yml` for profile links
